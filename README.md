# 館内案内（library-guide）

市立図書館の入口に置く、館内地図の案内ページ。

新刊・話題書コーナーや予約受取ロッカーで用を足した来館者が、他の棚や2階の郷土資料室、イベントに寄らず帰ってしまう。このページは、その場でスマートフォンから開き、目当ての本以外の場所に何があるかを知るためのもの。

新刊・話題書コーナーと予約受取ロッカーに、同じページを開く QR コードを置く。アプリのインストールは不要。

## このページでできること

- 1階と2階の館内地図を見る。
- スポットをタップして、名前、分類、説明を見る。
- 新刊・話題書コーナーと予約受取ロッカー以外の説明を開いた回数を、スポットごとに残す。

この回数は、来館者が中身を知るためにタップした数。その場所まで着いたことは分からない。ログインはなく、個人は識別しない。

## 今回は作らないもの

- おすすめ本の表示と、職員による差し替え
- イベントの印、一覧、カレンダー
- スタンプラリーと景品

## データ

館内スポット20件。各スポットには名前、分類、フロア、座標（メートル）、平均滞在時間（分）、説明がある。平均滞在時間は地図上には出さない。
